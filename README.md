## 核心功能详解

### 1. 自动化任务调度 ⭐
- **指令解析**：自动识别 /新建应用、/优化、/修复 三大指令
- **流程执行**：接收 → 解析 → 执行 → 反馈 全自动化
- **状态管理**：实时跟踪秒哒开发状态
- **无需人工干预**：整个流程自动完成

### 2. 多AI模型支持 🤖
支持以下AI模型生成需求文档：
- **豆包**（默认）
- **DeepSeek**
- **KIMI**
- **文心一言**
- **千问**
- **GPT**
- **智谱**

用户可通过指令指定模型，如：`/新建应用 模型:KIMI 开发网站`

### 3. 需求队列缓存 📋
- **繁忙不拦截**：秒哒开发中时自动收集新需求
- **智能合并**：将同一应用的多次需求整合为一份完整文档
- **自动执行**：秒哒空闲后自动发送合并后的需求
- **去重处理**：自动去除重复需求

### 4. 浏览器自动化 🌐
完整自动化操作流程：
1. 自动启动浏览器打开AI官网
2. 自动切换至思考模式
3. 自动输入需求内容
4. 等待AI生成结果
5. 自动点击"转为文档"
6. 自动下载保存到本地

### 5. 应用管理 📱
- **自动生成应用ID**：每个应用拥有唯一标识
- **状态跟踪**：待开发/开发中/测试中/已完成
- **URL管理**：开发链接、发布链接记录
- **历史追溯**：需求记录、BUG记录

### 6. 强制规范输出 📝
AI生成的需求文档必须包含：
- **前端PC端界面功能**：电脑端页面布局、按钮、操作效果
- **前端手机端界面功能**：仿APP风格、底部导航、按钮大小
- **管理后台界面功能**：登录、数据增删改查、权限控制

## 三大触发指令

| 指令 | 用途 | 示例 |
|------|------|------|
| `/新建应用` | 全新开发网站/游戏/小程序 | `/新建应用 开发一个企业官网` |
| `/优化` | 优化已有应用 | `/优化 APP-001 增加用户登录功能` |
| `/修复` | 修复BUG | `/修复 APP-001 首页按钮点击无反应` |

### 指定AI模型
```
/新建应用 模型:KIMI + 需求
/优化 应用ID 模型:DeepSeek + 需求
```

## 技术特性

### 零Token消耗
- 不调用OpenClaw自身大模型
- 仅做本地指令解析和自动化调度
- 所有需求文档由AI生成

### 串行开发管控
- 秒哒同一时间仅处理1个任务
- 繁忙时自动缓存需求
- 避免开发混乱

### 本地数据存储
- 应用信息：apps.json
- 任务队列：task_queue.json
- 任务状态：task_status.json
