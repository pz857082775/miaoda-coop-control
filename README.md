# 秒哒开发协作管控

[![版本](https://img.shields.io/badge/版本-1.1.0-blue)](https://github.com/mile-ai/miaoda-coop-control)
[![版权](https://img.shields.io/badge/版权-米乐-green)](https://github.com/mile-ai)
[![OpenClaw](https://img.shields.io/badge/OpenClaw-技能-orange)](https://github.com/openclaws)

作为 OpenClaw 的秒哒开发协作管控技能，适配网站、网页游戏、小程序、WAP、管理后台的新建、优化、修复全流程。

## 核心特性

| 特性 | 说明 |
|------|------|
| **多AI模型支持** | 豆包(默认)、DeepSeek、KIMI、文心一言、千问、GPT、智谱 |
| **纯中转原则** | 仅转达需求，不加工、不修改、不推理 |
| **自动化操作** | 全程浏览器自动化，无需人工干预 |
| **串行开发** | 秒哒同一时间仅处理1个任务 |
| **自动下载** | AI生成需求后自动转为文档下载本地 |
| **零Token消耗** | 不调用自身大模型 |

## 适用场景

- 网站开发
- 网站前端+管理后台
- 网页游戏
- 小程序
- WAP

## 三大触发指令

| 指令 | 用途 | 格式 |
|------|------|------|
| `/新建应用` | 全新开发 | `/新建应用 + 需求` |
| `/优化` | 功能优化 | `/优化 + 应用ID + 需求` |
| `/修复` | BUG修复 | `/修复 + 应用ID + BUG` |

### 指定AI模型
- `/新建应用 模型:KIMI + 需求`
- `/优化 应用ID 模型:DeepSeek + 需求`

## 模块化架构

1. **自动化任务核心模块** - 统筹全流程调度
2. **浏览器操作模块** - 自动化操作AI界面
3. **AI模型调度模块** - 多模型支持
4. **应用管理模块** - 应用ID绑定、状态管控
5. **指令交互模块** - 标准化输入输出
6. **异常处理模块** - 稳定运行保障

## 全流程

```
指令校验 → 模型调度 → 浏览器操作 → 需求生成 → 文档下载 → 本地存储 → 任务发送 → 成果同步
```

## 本地文档存储

- **目录**：`C:\OpenClaw_秒哒开发文档\`
- **命名**：`应用ID_应用名称_需求文档.docx`

## 安装

1. 下载压缩包
2. 解压到 OpenClaw skills 目录
3. 重启 OpenClaw
