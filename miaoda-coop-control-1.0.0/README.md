# miaoda-coop-control

[![版本](https://img.shields.io/badge/版本-1.0.0-blue)](https://github.com/mile-ai/miaoda-coop-control)

[![OpenClaw](https://img.shields.io/badge/OpenClaw-技能-orange)](https://github.com/openclaws)

秒哒开发协作管控技能 - 最终定型版。实现「需求生成-任务管控-开发跟进-测试反馈-迭代优化」全流程自动化。

## 功能特性

### 三大触发词

| 触发词 | 功能 |
|--------|------|
| `/新建应用` | 全新开发网站/游戏/小程序/后台 |
| `/优化` | 对已完成应用进行功能迭代 |
| `/修复` | 修复已开发应用的BUG |

### 核心功能

1. **强制浏览器豆包生成需求** - 100%通过豆包思考模式生成
2. **任务串行锁定** - 开发中禁止任何新指令
3. **极致降Token** - 零大模型推理消耗
4. **应用ID强绑定** - 自动同步秒哒回传信息
5. **全场景适配** - 网站/网页游戏/小程序/管理后台/WAP

### 支持场景

- 网站（PC+平板+手机仿APP）
- 网页游戏（PC+手机横竖屏自适应）
- 管理后台
- 小程序
- WAP

## 安装方法

1. 下载 `miaoda-coop-control-1.0.0.zip`
2. 解压到 OpenClaw skills 目录
3. 重启 OpenClaw

## 使用方式

```
/新建应用 + 需求描述  → 全新开发
/优化 + 应用ID        → 功能迭代
/修复 + 应用ID        → BUG修复
```

## 工作流程

```
用户发送指令
    ↓
OpenClaw 拦截校验（本地处理，零Token）
    ↓
浏览器自动化 → 打开豆包 → 思考模式
    ↓
豆包生成需求文档
    ↓
本地处理 → 生成应用ID → 缓存需求
    ↓
发送秒哒 → 标记状态
    ↓
通知用户
```

## 降Token策略

1. **OpenClaw零生成** - 需求全部由浏览器豆包生成
2. **指令本地固化** - 引导指令本地存储
3. **本地解析指令** - /新建/优化/修复本地识别
4. **轻量化传输** - 仅传输需求文档给秒哒
5. **本地记忆管理** - 应用信息本地存储
